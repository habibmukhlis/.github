### Featured Projects & Tools

#### Flagship Studio Products
- **AmniGuard Firewall & NetBlock** — High-performance, no-root Android firewall processing network packets 100% locally with an 80,000+ domain sinkhole and live PCAP Wireshark packet capture.
  - *Tech:* `Android VpnService` • `Kotlin` • `Compose` • `Port 853 DoT`
- **AmniShield Focus & Protection Suite** — Multi-platform digital wellness guardian (Android, Windows, WebExtensions) blocking explicit content and enforcing focus schedules with offline NIST P-256 ECDSA licensing.
  - *Tech:* `Kotlin` • `Accessibility API` • `Reels Blocker` • `NIST P-256`
- **Platen: 3D Typewriter** — Sovereign 3D mechanical typewriter simulator with spatial procedural Web Audio synthesis and zero-width cryptographic steganography.
  - *Tech:* `Three.js r185` • `Web Audio API` • `Authorship Proof` • `PWA`
- **AmniSpace Focus Launcher** — Minimalist proof-of-work Android focus launcher requiring task completion proof before unlocking distracting applications.
  - *Tech:* `Android 8.0+` • `Jetpack Compose` • `Zero Telemetry`
- **AmniBlur Web Extension** — Real-time on-device AI visual content moderation extension using local TensorFlow.js to automatically mask explicit content.
  - *Tech:* `TensorFlow.js` • `WebGL / WASM` • `Manifest V3`
